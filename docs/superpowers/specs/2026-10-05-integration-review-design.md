# 第五天：功能串联与复习设计

## 目标

把文章列表、文章详情和登录状态串成完整可演示流程，并增加退出登录，让 Riverpod 的全局状态共享更直观。最后整理项目架构与常见面试题，形成五天学习闭环。

## 用户流程

1. 启动应用并加载文章列表。
2. 点击文章进入详情页，返回后仍保留列表页面。
3. 未登录时从首页进入登录页，成功后首页显示用户名。
4. 点击用户名打开账户面板。
5. 点击退出登录，请求玩安卓退出接口、清理 Cookie，并让首页自动恢复登录入口。

## 技术方案

- 沿用 Flutter `Navigator` 与 `MaterialPageRoute` 完成列表、详情和登录页面导航。
- 沿用 Riverpod `AuthController` 保存全局登录状态，账户面板只触发退出动作。
- `AuthService` 请求 `GET /user/logout/json`，并在请求完成后始终尝试清理持久化 Cookie。
- 登录与退出通过异步队列串行执行，避免多个认证请求交叉修改同一个 Cookie 容器。
- 退出期间展示加载状态并阻止关闭面板；失败时重置界面登录状态并给出提示。
- Widget 测试通过 Provider override 注入假仓库，验证跨页面状态变化。

## 范围

- 本次实现退出登录、账户面板、串联测试和面试复习文档。
- 不增加注册、收藏、分页、深层链接或新的路由框架。
- 所有提交信息使用中文，并按小功能拆分提交。
